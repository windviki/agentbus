# Code of conduct

This project follows the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful of different backgrounds, experience levels and tools.
- Critique ideas and code, not people.
- Harassment, personal attacks, and publishing others' private information are
  not acceptable.
- Maintain a harassment-free experience for everyone, regardless of identity.

Reports go to the maintainers via a private GitHub issue or the repository
owner listed in `package.json`. Maintainers will review and respond in good
faith; enforcement may range from a warning to a permanent ban from the
project's spaces.

This code applies in issues, pull requests, discussions and any other space
where the project is represented.
